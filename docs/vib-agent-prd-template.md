## 模板使用指南

| 章节 | 必须 | 说明 |
|------|------|------|
| 背景与动机 | 是 | 解释为什么做，引用用户反馈或数据 |
| 目标 / 非目标 | 是 | 明确范围，防止 scope creep |
| 用户流程 | 是 | 包含主流程和至少 3 个异常流程 |
| 数据模型 | 是 | TypeScript interface + 字段说明 |
| 授权与安全边界 | 否，涉及三方数据时必填 | 明确允许和禁止的数据范围 |
| 状态机 | 是，涉及多步骤流程时必填 | ASCII 状态图 |
| 验收标准 | 是 | 至少 3 条，P0 必须包含测试方法 |
| 依赖 | 是 | 列出外部 API、三方 SDK、内部模块 |
| 开放问题 | 是 | 记录未决策的事项 |

## PRD 生命周期

```
DRAFT → REVIEW → APPROVED → (实现) → OBSOLETE
                ↘ REJECTED
```

| 阶段 | 说明 |
|------|------|
| DRAFT | 初稿，讨论中 |
| REVIEW | 评审中，收集反馈 |
| APPROVED | 已批准，可进入开发 |
| OBSOLETE | 已废弃，不再使用 |
| REJECTED | 评审未通过 |
