## Task 4-1：排版前后差异报告

### 产品逻辑

修复完成后，展示 Before/After 差异报告，让用户确信：①修复了该修的 ②没动不该动的。

### 交互规格

**1. 差异报告页面（修复完成后自动展示）**

```
┌──────────────────────────────────────────────────────────┐
│                                                           │
│  📊 修复报告                                              │
│                                                           │
│  ┌─────────────┐                                          │
│  │  62 → 96    │  得分提升（大字号，绿色箭头动画）         │
│  └─────────────┘                                          │
│                                                           │
│  ✅ 你的论文内容未被修改，仅调整了格式                     │
│  （内容指纹校验通过，原稿与修正稿正文完全一致）            │
│                                                           │
│  ──────────────────────────────────────────               │
│                                                           │
│  修复摘要                                                 │
│  ✅ 页边距：左边距 25mm → 30mm                            │
│  ✅ 正文字体：修复 47 处英文字体                          │
│  ✅ 行距：全文 128 段统一为 1.25 倍                       │
│  ✅ 标题层级：修复 25 处标题样式                          │
│  ✅ 页码：前置页改为罗马数字，正文从 1 开始               │
│  ✅ 封面：日期格式已修正                                  │
│  ✅ 目录：已重新生成，页码已更新                          │
│  ✅ 查重风险：已修复 3 项，预计影响降低 4%                │
│                                                           │
│  ⚠️ 1 处脚注格式需手动检查（第 12 页）                    │
│                                                           │
│  ──────────────────────────────────────────               │
│                                                           │
│  [ 📄 查看逐页对比 ]   [ 📦 确认导出 ]                    │
│                                                           │
└──────────────────────────────────────────────────────────┘
```

**2. 逐页对比模式**

点击"查看逐页对比"进入 Before/After 双栏预览（复用已有的差异预览组件）：
- 左栏 BEFORE · 原稿
- 右栏 AFTER · 修正稿
- 差异高亮：三级色彩体系（结构/格式/内容）
- 同步滚动，默认锁定
- 缩略图导航带变更密度条

**3. 得分提升动画**

- 旧分数和新分数之间有数字滚动动画（800ms）
- 新分数用绿色大字号展示
- 如果新分数 ≥ 95，额外显示"🎉 优秀！可以放心提交"

## Task 4-2：确认导出

### 交互规格

**1. 导出确认面板**

```
┌──────────────────────────────────────────────────┐
│                                                   │
│  📦 导出确认                                      │
│                                                   │
│  ✅ 格式修复：8 项已自动修正                      │
│  ✅ 查重预处理：3 项已优化                        │
│  ✅ 正文内容：与原稿完全一致                      │
│  ⚠️ 你忽略了 1 项建议（脚注格式，第 12 页）       │
│                                                   │
│  ──────────────────────────────────────           │
│                                                   │
│  文件名：                                         │
│  [ 毕业论文_复旦管理学院_20260508.docx    ✎ ]    │
│                                                   │
│  [ 📥 下载修正稿 ]                                │
│                                                   │
│  ──────────────────────────────────────           │
│                                                   │
│  同时下载：                                       │
│  ☐ 原稿（未修改版本）                            │
│  ☐ 修改清单（TXT 格式）                          │
│  ☐ 格式体检报告（可分享）                        │
│                                                   │
└──────────────────────────────────────────────────┘
```

**2. 文件名自动生成**

```
{原文件名}_{学校简称}{学院简称}_{YYYYMMDD}.docx
```

可编辑：点击 ✎ 变为 input 框。

**3. 附件导出**

| 附件 | 说明 |
|------|------|
| 原稿 | 未经任何修改的原始 DOCX |
| 修改清单 TXT | 结构化的修改条目列表（见下方格式） |
| 格式体检报告 | HTML 页面，含得分、问题清单、修复记录（可分享） |

修改清单 TXT 格式：
```
修改清单 — 毕业论文.docx
学校：复旦大学 | 学院：管理学院 | 规范：v2024.01
检测时间：2026-05-08 14:32

[自动修复] 页边距 | 左边距 25mm → 30mm
[自动修复] 正文字体 | Arial → Times New Roman（47 处）
[自动修复] 行距 | 1.5倍 → 1.25倍（128 段）
[自动修复] 标题层级 | 应用 Heading 2/3 样式（25 处）
[自动修复] 页码格式 | 前置页阿拉伯 → 罗马数字
[自动修复] 封面日期 | 2026年5月 → 二〇二六年五月
[自动修复] 目录 | 重新生成
[自动修复] 查重预处理 | 修复 3 项
[未修复]   脚注格式 | 第 12 页 · 需手动检查

正文内容指纹校验：通过（原稿与修正稿正文一致）
```

**4. 阻断条件**

如果存在未处理的失败项（severity=error 且 fixable=true 但未修复），阻断导出：
```
❌ 还有 2 项格式问题未修复，无法导出。
   [ 返回修复 ]
```

### 接口定义

```typescript
// 导出
POST /api/export
Body: {
  fixedFileId: string;
  fileName?: string;          // 自定义文件名
  includeOriginal: boolean;
  includeChangeLog: boolean;
  includeReport: boolean;
}
Response: {
  downloadUrl: string;        // 修正稿下载链接
  originalUrl?: string;       // 原稿下载链接
  changeLogUrl?: string;      // 修改清单下载链接
  reportUrl?: string;         // 体检报告 URL（HTML 页面）
  expiresAt: string;          // 下载链接有效期（7 天）
}
```

## Task 4-3：打印预览模拟

### 产品逻辑

在导出前增加"预览打印效果"入口，让学生确认纸质版输出效果。

### 交互规格

导出确认面板中增加一个按钮：

```
[ 🖨 预览打印效果 ]
```

点击后：
- 将修正稿转为 PDF 预览（服务端渲染）
- 在新标签页或弹窗中展示 PDF 预览
- 预览中标注：
  - 页边距区域（淡灰色虚线框）
  - 装订线位置（如适用）
  - 页码位置

```
┌──────────────────────────────────────────┐
│  🖨 打印预览                              │
│                                           │
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐ │
│  │                                     │ │
│  │  ┌─────────────────────────┐       │ │
│  │  │                         │       │ │
│  │  │    论文内容渲染         │       │ │
│  │  │                         │       │ │
│  │  └─────────────────────────┘       │ │
│  │              — 1 —                  │ │
│  │                                     │ │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘ │
│                                           │
│  ← 第 1 页 / 共 32 页 →                  │
│                                           │
│  纸张：A4 | 页边距：上25/下25/左30/右25mm │
│                                           │
│  [ 关闭预览 ]       [ 📥 下载修正稿 ]     │
└──────────────────────────────────────────┘
```

### 接口

```typescript
// 生成打印预览
POST /api/preview-pdf
Body: { fixedFileId: string }
Response: { pdfUrl: string; pageCount: number }
```

### 实现说明
- 后端用 LibreOffice headless 或 docx-to-pdf 库将 DOCX 转为 PDF
- PDF 在前端用 iframe 展示（不用 PDF.js，直接浏览器内置渲染）
- 如果转换耗时较长（> 5 秒），显示 loading + "正在生成预览..."
