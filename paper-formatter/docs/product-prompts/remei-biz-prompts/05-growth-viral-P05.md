## 背景

毕业季（4-6 月）是需求爆发期，错过就要等一年。
本科生的传播链路：寝室群 → 班级群 → 同专业群 → 跨专业口碑。
核心机制：**学生 A 看到体检报告 → 分享到群里 → 学生 B 好奇试试 → 免费体检 → 付费修复**。

关键洞察：学生分享的动机不是"推荐好工具"，而是**"看看我论文还有这么多格式问题lol"**——自嘲式分享，社交货币。

**设计要点**：
- 分数醒目（大字号 + 颜色编码）
- 只展示前 4-5 个问题（制造"居然还有这么多"的感觉）
- CTA 按钮"免费检测我的论文"是全页最大的操作元素
- 底部"已有 N 位同学使用"是社会证明（初期可用预设数字，后期接真实数据）
- 页面不展示该用户的任何个人信息（无姓名、学号、论文标题）——保护隐私

## Task 5-2：裂变数据追踪

### 产品逻辑

追踪分享链路，衡量裂变效果，优化分享策略。

### 数据埋点

| 事件 | 触发点 | 参数 |
|------|--------|------|
| share_click | 点击"复制链接"或"生成海报" | source（result_page / export_page / fix_complete） |
| share_page_view | 新用户打开分享页 | shareId, referrer |
| share_page_cta_click | 新用户点击"免费检测" | shareId |
| share_to_upload | 新用户从分享页进入并上传文档 | shareId |
| share_to_pay | 新用户从分享链路最终付费 | shareId, amount |

### 关键指标

```
分享率 = 分享次数 / 体检完成数
打开率 = 分享页 PV / 分享次数
转化率 = 上传数 / 分享页 PV
付费转化率 = 付费数 / 上传数
裂变系数 = 每个付费用户带来的新付费用户数
```

目标（毕业季）：
- 分享率 > 15%（每 7 个体检用户中有 1 个分享）
- 打开率 > 40%（群聊场景点击率高）
- 转化率 > 25%（看到分数后好奇心驱动）
- 裂变系数 > 0.3（每 3 个付费用户带来 1 个新付费）

### 数据看板需求

后台增加裂变数据看板（管理员可见）：
- 每日分享数 / 打开数 / 转化数 趋势图
- 按学校维度的分享热力图（哪些学校传播最强）
- 分享链路漏斗图（分享 → 打开 → 上传 → 付费）
