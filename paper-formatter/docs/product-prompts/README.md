# Product Prompts Archive

This directory preserves product and commercialization prompt packs that were previously parked under `services/client`.

These files are planning assets, not runtime client code:

- `remei-prompts/` covers UX iteration tasks for the paper formatting client.
- `remei-biz-prompts/` covers commercialization, growth, delivery trust, and value-add feature planning.

Keep prompt packs here unless they become executable product specs or formal architecture documents.
