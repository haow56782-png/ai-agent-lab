# remei 商业化 — 03 查重前预处理（P0·高付费动机）

> 前置依赖：先加载 `00-global-context.md`，确认 `01` `02` 已完成
> 本文件 2 个 task | 商业角色：卡住"查重"这个比排版更痛的节点

---

## 背景

本科生交稿流程：排版 → 查重 → 提交。
很多学生不知道**格式问题会影响查重结果**：
- 目录内容如果没有用 Word 域（而是手打的），知网会把目录当正文算重复
- 页眉页脚中的论文标题会被算入正文
- 参考文献列表如果格式不规范，可能不被识别为引用而算重复
- 脚注/尾注内容如果格式混乱，可能被合并到正文计算

这意味着：**仅仅修复格式问题，就可能让查重率降低 3-8 个百分点**。

这是一个极强的付费触发点——查重不过可能延期毕业，比格式被打回严重得多。

**2. 视觉设计**

- 整体卡片使用浅橙色警告底色，与普通格式问题的白色底色区分
- "影响查重率"几个字加粗 + 橙色
- "预计可降低 3-5 个百分点"使用绿色，制造正向预期
- 卡片在页面中的位置高于普通格式问题，优先被看到

**3. 降低值计算逻辑**

```
预估降低值 = 影响问题数 × 单项平均影响系数
  - 手打目录：~2%（目录通常占全文 1-3 页）
  - 页眉含标题：~0.5%（每页重复一次）
  - 参考文献格式问题：~1-3%（取决于引用数量）
  - 脚注混乱：~0.5-1%
```

**注意：这是估算值，需要在界面中标注"预计"，避免承诺准确降幅。**

### 检测规则

```typescript
interface DuplicationRisk {
  id: string;
  type: 'manual_toc' | 'header_content' | 'reference_format' | 'footnote_format' | 'watermark_text';
  title: string;
  description: string;       // 面向学生的解释
  estimatedImpact: number;   // 预估对查重率的影响百分点
  fixable: boolean;
  severity: 'high' | 'medium' | 'low';
}
```

## Task 3-2：查重预处理修复

### 产品逻辑

用户点击"一键修复查重风险项"后，执行以下修复：

### 修复项

| 检测项 | 修复操作 | 技术实现 |
|--------|---------|---------|
| 手打目录 | 删除手打目录，基于标题层级重新生成 Word 域目录 | 依赖 Task 2-3 标题层级修复 + Task 2-6 目录生成 |
| 页眉含论文标题 | 保留页眉但确保格式正确（学校要求的内容保留，多余内容清除） | 页眉内容对比规范，多余部分清理 |
| 参考文献格式 | 修正不规范的引用格式，确保查重系统能识别为引用 | 正则匹配 + 格式重写 |
| 脚注混乱 | 标记问题位置，生成修复建议（不自动修复，风险较高） | 检测 + 建议 |

### 修复后展示

```
✅ 查重风险已修复

  ✅ 目录已重新生成（使用 Word 自动目录）
  ✅ 页眉内容已清理
  ✅ 3 条参考文献格式已修正
  ⚠️ 1 处脚注格式需手动检查（第 12 页）

  修复前预估查重影响：+4.5%
  修复后预估查重影响：+0.5%
  
  💡 建议：修复后重新提交查重，查重率有望改善。
```

### 接口（复用 02 的修复接口，增加 fixType）

```typescript
// 在 POST /api/fix 的 fixTypes 中增加：
fixTypes: [..., 'duplication_preprocess']
```

### 付费策略

查重预处理属于高价值功能，有两种定价策略可选：

**策略 A：包含在基础修复套餐中**
- 9.9 元套餐同时包含格式修复 + 查重预处理
- 好处：简化决策，提高整体套餐价值感

**策略 B：作为独立增值项**
- 基础格式修复 9.9 元
- 查重预处理额外 +4.9 元
- 好处：提高客单价，且学生对"降低查重率"的付费意愿可能更高

**建议选择策略 A**：MVP 阶段不要让用户在多个 SKU 间犹豫，一口价降低决策成本。
