## 产品定位

remei 是一个 **本科毕业论文排版格式自动检测+修复** 的 Web 端工具。

核心价值主张：上传论文 → 自动检测格式问题 → 一键修复 → 导出可提交的 DOCX

**商业模式**：免费体检（看到问题）→ 付费修复（解决问题）→ 导出交付（完成闭环）

**唯一目标用户：本科毕业生**。不考虑研究生/导师/学院管理员。

---

## 用户画像

- 22 岁左右，非技术背景为主
- Word 操作能力：初级（不理解"节"、"域"、"样式"等概念）
- 核心焦虑：论文格式被打回 → 延期毕业
- 付费决策链路：免费试一下 → 看到问题清单 → "原来这么多问题" → 付费修复
- 时间窗口：每年 4-6 月毕业季，需求爆发式集中
- 社交传播：寝室群、班级群、同专业微信群是主要传播渠道

---

## 技术栈

- 前端：React 18+ / Tailwind CSS / Zustand
- 后端：Node.js（假设，根据实际调整）
- 文档处理：服务端 DOCX 解析与修改（python-docx / docx4j / 自研引擎）
- 存储：用户上传文件临时存储，处理完成后保留 7 天
- 部署：Web 端，无需安装

---

## 全局设计原则

1. **免费功能必须让用户看到足够多的问题**——问题越多，付费动机越强
2. **付费功能必须让用户看到立竿见影的修复效果**——Before/After 对比是转化核心
3. **所有文案用学生语言**——不说"样式"说"字体字号"，不说"分节"说"页码设置"
4. **每个功能都要有明确的"完成感"**——进度条、✓ 标记、"已修复"标签
5. **不碰论文内容**——只改格式，反复强调"不修改你的文字内容"

---

## 付费墙设计原则

- 免费功能：格式体检（看到所有问题）+ 前 3 项自动修复（体验价值）
- 付费触发：第 4 项修复开始 → 弹出付费墙
- 付费后：解锁全部修复 + 导出 + 差异报告
- 定价锚点：一杯奶茶的价格（9.9-19.9 元单次），学期卡 39.9 元

## 执行纪律

1. 按文件编号顺序执行：01 → 02 → 03 → 04 → 05 → 06
2. 每个文件内部按 task 编号顺序执行
3. 每完成一个 task，暂停汇报：做了什么、改了哪些文件、遗留问题
4. 等待确认后再进入下一个 task
5. 涉及后端接口的 task，先输出接口定义（TypeScript interface），确认后再写实现
6. 涉及付费墙的 task，标注付费触发点和免费/付费边界
