# VIB AI 数据采集 & 标注系统

> 基于 Figma 设计稿 `AI Agent 游戏预测` 精确还原

## 概述

VIB AI 平台内置**数据贡献中心**，通过任务化、激励化的方式让用户参与 AI 训练数据的采集与标注。支持多种数据类型：图片、视频、语音、快判任务。

平台 slogan：*"我们致力于为全球领先的大模型提供高质量训练数据"*

---

### 大模型切换 (Bottom Sheet)

**交互**：点击模型名称 → 从底部弹出模型选择面板

**底部面板设计** (Bottom Sheet)：
- 圆角：`radius=30px`（顶部两角）
- 背景：毛玻璃效果 `#292929 @ 0.8` 透明度
- 遮罩：`#000000 @ 0.6`
- 提供免费模型和付费模型两个层级

**模型列表**：
| 模型 | 类型 | 标识 |
|------|------|------|
| Grok 3 | 免费/付费 | 品牌主推 |
| Grok 4 | 付费 | 高级版本 |
| Grok 8 | 付费/旗舰 | 128px 大标题 |

### 对话状态

| 状态 | 设计 |
|------|------|
| 初始态 | 问候语 + 推荐任务卡片 |
| 输入中 | 底部输入框聚焦，显示发送按钮 |
| 思考动画 | 动态加载指示器 |
| 回复完成 | 气泡显示 + 信号卡片 |
| 回复失败 | 红色错误提示 + 重试按钮 |

## 二、图片采集系统

### 流程

```
选择任务主题 → 选择采集类型 → 上传图片 → 完成任务
```

### 页面风格

图片采集部分使用**浅色主题**（与其他页面的深色模式不同）：
- 背景色：`#F5F4F7`
- 卡片背景：`#FFFFFF`
- 文字色：`#231C2F`
- 圆角：`radius=16px`（卡片），`radius=6px`（头像）
- 聊天气泡：`#EAE6F1`（AI 消息背景）

### 采集类型选择

图片采集提供两种模式：
1. **普通模式** — 直接从预设主题中选择
2. **自定义模式** — 用户自定义主题并上传

### 自定义主题输入

| 状态 | 设计 |
|------|------|
| 未选中 | 空输入框 |
| 选中 (聚焦) | 输入框高亮边框 |
| 已输入 | 显示输入内容 |
| 已上传 | 显示缩略图预览 |

## 四、快判任务系统 (Quick Judgment)

### 快速标注/判断任务

```
┌──────────────────────────────┐
│  Grok 3 [模型名称]            │
│                              │
│  "请选择文件类型："            │
│                              │
│  ┌── Task Card (radius=30) ─┐│
│  │  ┌──────────────────┐    ││
│  │  │  📷 图片快判      │    ││ ← #262626 radius=16px
│  │  └──────────────────┘    ││
│  │  ┌──────────────────┐    ││
│  │  │  🎬 视频快判      │    ││
│  │  └──────────────────┘    ││
│  │  ┌──────────────────┐    ││
│  │  │  💬 语音快判      │    ││
│  │  └──────────────────┘    ││
│  └──────────────────────────┘│
│                              │
│  [输入框: Ask Anything]      │
└──────────────────────────────┘
```

### 难度等级系统

快判任务支持三级难度：

| 等级 | 对应关系 | 设计 |
|------|---------|------|
| **简单** | ⭐ 单星 | 基础判断任务 |
| **中等** | ⭐⭐ 双星 | 需要更多分析 |
| **复杂** | ⭐⭐⭐ 三星 | 高级标注任务 |

### 难度选择界面特性
- 每个难度都有独立的说明页面
- 不同难度的任务卡片数量不同
- 复杂任务支持更长的页面（scroll）

### 统计卡片

```
┌──────────────────┐
│ 今日收益          │ ← 标签 text-secondary
│ +$2,450          │ ← 数值 large + 金色/绿色
│ ↑ 12.5%          │ ← 趋势
└──────────────────┘
```

### 任务卡片组件

```css
/* Task Card — 核心复用组件 */
.vib-task-card {
  background: #1C1C1C;        /* 卡片容器 */
  border-radius: 30px;         /* 外圆角 */
  padding: 16px;
}

.vib-task-card__item {
  background: #262626;         /* 内部项背景 */
  border-radius: 16px;         /* 内圆角 */
  padding: 12px 16px;
}

.vib-task-card__icon {
  width: 48px; height: 48px;
  border-radius: 14.4px;       /* ≈14px 图标容器圆角 */
}
```

## 七、设计规范补充

### 采集/标注相关的 Token 补充

```css
/* 浅色采集主题 (仅图片采集) */
--vib-collect-bg:      #F5F4F7;
--vib-collect-card:    #FFFFFF;
--vib-collect-text:    #231C2F;
--vib-collect-bubble:  #EAE6F1;

/* 任务/标注组件 */
--vib-task-bg:         #1C1C1C;    /* 任务卡片容器 */
--vib-task-item:       #262626;    /* 任务卡片内项 */
--vib-task-radius:     30px;       /* 任务卡片圆角 */
--vib-task-radius-inner: 16px;     /* 内部项圆角 */
--vib-icon-radius:     14.4px;     /* 图标容器圆角 */

/* 底部面板 (模型切换) */
--vib-sheet-bg:        rgba(41, 41, 41, 0.8);  /* 毛玻璃 */
--vib-sheet-radius:    30px;
--vib-sheet-overlay:   rgba(0, 0, 0, 0.6);
```

### 采集/标注流程组件规格

| 组件 | 圆角 | 背景色 | 文字色 |
|------|------|--------|--------|
| Task Card (容器) | 30px | #1C1C1C | — |
| Task Item (选项) | 16px | #262626 | #FFFFFF |
| 图标容器 | 14.4px | — | — |
| 输入框 | 30px | #202020 | #6E6E6E (placeholder) |
| AI 消息气泡 (深色) | 16px | #262626 | #FFFFFF |
| AI 消息气泡 (浅色) | 16px | #EAE6F1 | #231C2F |
| 用户消息气泡 | 16px | #4E41FF | #FFFFFF |
| Status Bar 文字 | — | — | #FFFFFF (17px) |
